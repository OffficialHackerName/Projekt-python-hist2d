INSTRUKCJA UŻYTKOWNIKA:
1. WYMAGANE ŚRODOWISKO:

   - Python 3.14
   - Wymagane biblioteki (zobacz P3Tem09_requirements.txt)

2. INSTALACJA:

   - Zainstaluj zależności: pip install -r P3Tem09_requirements.txt
   - Lub ręcznie: pip install pandas matplotlib numpy openpyxl

3. URUCHOMIENIE PROGRAMU  Z LINII POLECEŃ:

   - py P0Tem09.py

4. STRUKTURA DANYCH WEJŚCIOWYCH:

   - Plik Excel (.xlsx lub .xls) zawierający kolumny: 'X' i 'Y'
   - Kolumny mogą zawierać dane liczbowe (całkowite lub zmiennoprzecinkowe)
   - Przykładowe dane w pliku P3Tem09.xlsx I P3Tem09_błędne_dane.xlsx

5. OBSŁUGA PROGRAMU:

   - Po uruchomieniu pojawia się okno z 3 przyciskami:
     
     a) [Wybieram plik z danymi] - wczytaj własny plik Excel z kolumnami X i Y
     b) [Generuj dane losowo] - utwórz histogram z 100 losowych punktów
     c) [Wyjdź] - zamknij okno aplikacji
   
   - Po wybraniu pliku lub generowaniu losowym:
     * Program tworzy histogram 2D (mapę cieplną)
     * Oś X i Y są automatycznie opisane
     * Pasek kolorów pokazuje gęstość punktów
     * Wykres otwiera się w nowym oknie matplotlib

6. TESTY:

    - Test 1: Uruchomienie przycisku "Generuj dane losowo"
     * Oczekiwany wynik: wykres z losowym rozkładem punktów
   
   - Test 2: Wczytanie poprawnego pliku Excel
     * Oczekiwany wynik: wykres na podstawie danych z pliku
   
   - Test 3: Wczytanie niepoprawnego pliku (bez kolumn X,Y)
     * Oczekiwany wynik: komunikat "nieprawidłowy plik" w konsoli
   
   - Test 4: Anulowanie wyboru pliku
     * Oczekiwany wynik: komunikat "nie wybrałeś żadnego pliku"

7. STRUKTURA PROJEKTU:

    P3Tem09.py - główny plik programu
    P3Tem09.xlsx - plik z danymi
    P3Tem09_błędne_dane.xlsx - plik z błędnymi danymi
    P3Tem09_requirements.txt - plik z nazwami wymaganych modułów

8. ALGORYTM:

   Krok 1: Inicjalizacja GUI
   - Utworzenie okna Toplevel jako dziecka okna głównego
   - Dodanie 3 przycisków z funkcjami callback

   Krok 2: Obsługa wyboru pliku
   - Otwarcie okna dialogowego do wyboru pliku Excel
   - Wczytanie danych za pomocą pandas.read_excel()
   - Walidacja obecności kolumn 'X' i 'Y'

   Krok 3: Generowanie danych losowych
   - Wygenerowanie 100 punktów (x,y) z rozkładu normalnego
   - Użycie numpy.random.randn() do losowania

   Krok 4: Tworzenie histogramu 2D
   - Podział przestrzeni na siatkę 10x10 komórek (bins=10)
   - Zliczenie punktów w każdej komórce
   - Mapowanie gęstości na kolory (colormap 'inferno')

   Krok 5: Wizualizacja
   - Wyświetlenie mapy cieplnej za pomocą plt.hist2d()
   - Dodanie paska kolorów (colorbar)
   - Opisanie osi i tytułu
   - Prezentacja w osobnym oknie matplotlib

   Krok 6: Czyszczenie
   - Zamknięcie okna aplikacji przyciskiem "Wyjdź"
   - Zwolnienie zasobów przez matplotlib
